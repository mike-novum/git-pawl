/goal

Надо изучить описанные задачи (баги, замечания, улучшения, новый функционал), проанализировать их, разбить на задачи.

Задачи пускать в работу  используя subagent-driven подход:
- запускай последовательно сабагентов;
- 1 сабагент выполняет разработку и исправления кода, 2 делает проверку результата за первым, в случае нахождения замечания перенаправляет их обратно первому сабагенту;
- Задача считается завершенной когда второй агент подтвердил что задача исполнена должным образом;
- по окончанию каждой задачи сделать коммит в гит;
- Проверяющий агент должен прибегать к использованию playwright mcp и chrome-dev-tools mcp чтобы проверять работоспособность некоторого функционала.


Чек-лист для проверки задачи:
- npm run tsc, npm run lint выполняются без ошибок;
- приложение запускается без ошибок в консоли дев-сервера;
- сборка билда происходит без ошибок;
- сабагент-ревьювер проверил через playwright mcp или chrome-dev-tools mcp функционал по постановке задачи;
