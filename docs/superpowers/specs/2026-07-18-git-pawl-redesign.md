# git-pawl: редизайн основного интерфейса

> Дата: 2026-07-18
> Статус: на согласовании
> Область: UI/UX основного приложения (chrome, workspaces, repository)

## Цель

Переработать основной интерфейс git-pawl: уйти от «sidebar на 250px с 3 пунктами» к горизонтальной шапке + экрану тайлов воркспейсов как домашнему экрану. Переработать страницу репозитория — убрать перегруз из 4 панелей. Зафиксировать визуальный язык (тёмный технический, Linear/Arc-style).

## Не входит в скоуп

- Изменения в git-движке main-процесса (TASK-021..025) — это уже сделано
- Новые аккаунты/провайдеры (GitLab OAuth и т.п.) — отдельная задача
- Глобальные настройки как таковые (тема, editor, fetch interval) — переезжают в новый layout без функциональных изменений
- Темизация светлой темой как самостоятельная фича — её доведём до ума в рамках дизайн-токенов

- Длительности: `--duration-fast: 120ms`, `--duration-base: 180ms`

## 2. Хром (горизонтальная шапка)

Шапка — **единственная навигация** на всех страницах кроме тайлов воркспейсов. Высота 48px, фон `--surface`, нижняя граница `--border`.

### 2.1. Структура на странице воркспейса, репозитория, настроек, аккаунтов

```
┌──────────────────────────────────────────────────────────────────┐
│  ‹  ▾ {workspace-name}                          ⚙  ◐             │
└──────────────────────────────────────────────────────────────────┘
```

**Левая зона:**
- **Back-шеврон** `‹`: виден только когда есть откуда возвращаться. Клик → `navigate(-1)` если есть история, иначе жёсткий `navigate('/workspaces')`. Кнопка 32×32, скругление 8.
- **Workspace selector** `▾ {name}`: дропдаун. Содержимое:
  1. Список всех воркспейсов с чекмарком на активном
  2. Сепаратор
  3. `+ New workspace…` — открывает CreateWorkspaceDialog
  4. `Manage workspaces…` — ведёт на `/workspaces`

**Правая зона:**
- **Settings** `⚙`: 32×32 icon-only, ghost-кнопка, hover `surface-elevated`. Ведёт на `/settings`.
- **Theme toggle** `◐`: такая же форма. Иконка `Moon` в тёмной теме, `Sun` в светлой. Tooltip `Switch to light/dark`.

### 2.2. Структура на странице тайлов воркспейсов

```
┌──────────────────────────────────────────────────────────────────┐
│  git-pawl                                       ⚙  ◐             │
└──────────────────────────────────────────────────────────────────┘
```

- Слева: текстовый лого `git-pawl` (или иконка + текст, в темплейте уже есть иконка лапы — переиспользуем)
- Справа: те же Settings + Theme
- Back и workspace selector отсутствуют — мы и так «дома»

### 2.3. Компонентная декомпозиция

- `widgets/app-header` — шапка со слотами left/right
- `widgets/workspace-selector` — выносим из текущего `widgets/workspace-switcher`, переименовываем и адаптируем под новый chrome
- `widgets/settings-button`, `widgets/theme-button` — мелкие переиспользуемые кнопки

### 2.4. Что выпиливается

- Текущий `<aside>` из `AppLayout` уходит полностью
- `NAV_ITEMS` (Workspace / Accounts / Settings) — удаляются, навигация теперь через back + селектор + иконки
- `AppLayout` остаётся, но рендерит только `<AppHeader />` + `<Outlet />`

### 2.5. Роутинг

| Path | Страница |
|---|---|
| `/workspaces` | Тайлы воркспейсов (бывший `/workspace`) |
| `/workspaces/:id` | Страница воркспейса со списком репо |
| `/repos/:id` | Страница репозитория (бывший `/repo/:id`) |
| `/settings` | Настройки |
| `/accounts` | Аккаунты (на верхнем уровне, не внутри Settings) |
| `/clone` | Клонирование |

Реэкспорт старых путей через `<Navigate>` чтобы не сломать сохранённые ссылки.

## 3. Экран тайлов воркспейсов

Это «дом» приложения. Сюда попадаем по back-шеврону с любой страницы.

### 3.1. Структура

```
┌──────────────────────────────────────────────────────────────────┐
│  git-pawl                                       ⚙  ◐             │  ← шапка
├──────────────────────────────────────────────────────────────────┤
│  Workspaces                                          + New       │  ← H1 + CTA
│  3 workspaces · last activity 2 hours ago                        │  ← мета
│                                                                  │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐         │
│  │ 🐱       │  │ 💼       │  │ 🧪       │  │   ＋      │         │
│  │ Pet-proj │  │ Work     │  │ Labs     │  │ New      │         │
│  │ 🟢 12    │  │ 🟡 47    │  │ 🟢 8     │  │ workspace│         │
│  │ 2h ago   │  │ yesterday│  │ 3d ago   │  │          │         │
│  │ 124 MB   │  │ 2.1 GB   │  │ 38 MB    │  │          │         │
│  └──────────┘  └──────────┘  └──────────┘  └──────────┘         │
│                                                                  │
│  Recent activity                                                 │
│  • last commit 2h ago in pet-proj/cat-feed                       │
│  • 3 commits pushed 1d ago in work/api-gateway                  │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

### 3.2. Hero

- Заголовок «Workspaces» — H1, 24/600
- Под ним строка-мета: `{N} workspaces · last activity {relative time}` — `--muted-foreground`
- Справа primary-кнопка `+ New` (не `+ New workspace` — компактнее)

### 3.3. Карточка воркспейса (плитка)

- Размер: **280×180px**
- Сетка: `grid-template-columns: repeat(auto-fill, minmax(280px, 1fr))`, gap 16px
- Содержимое:
  - Иконка (40×40, скругление 10): эмодзи или загруженная пользователем картинка. Если не задана — первая буква имени на цветном фоне (background генерится из хеша имени, через `oklch`)
  - Имя (16/500, truncate, 1 строка)
  - Счётчик репо: `{N} repos` или `{N} repo`
  - **Статус-точка:** 🟢/🟡/🔴
  - Последняя активность: relative time
  - Размер на диске: моноширинно, справа внизу
- Hover: `border-[var(--primary)]` + `--shadow-glow`

### 3.4. Алгоритм статус-точки (для плитки воркспейса)

1. Пробегаем по всем репо воркспейса (параллельно, с лимитом concurrency 4)
2. **Красный** — если хотя бы в одном репо отсутствует директория `.git` (пользователь случайно удалил) или `git rev-parse --git-dir` падает
3. **Жёлтый** — иначе если хотя бы в одном репо есть незакоммиченные изменения (включая untracked файлы)
4. **Зелёный** — все репо чистые и валидные
5. **Кеш:** результат кешируется на 30 секунд на уровне workspace store (zustand). При добавлении/удалении репо в воркспейсе кеш инвалидируется

### 3.5. Фича: сканирование размера на диске

- Новая функция в `entities/workspace`: `computeWorkspaceSize(workspacePath): Promise<number>` в bytes
- Реализация в `electron/main/services/fs.ts` через рекурсивный обход с игнорированием `node_modules` и `.git/objects`
- **Throttle:** вычисление запускается раз в 5 минут на плитку + при добавлении репо
- Отображается в human-readable: `124 MB`, `2.1 GB`, `38 KB`
- Тултип при ховере: «Disk size, scanned {relative time} ago»

### 3.6. Карточка «New workspace»

- Размер как у обычной плитки (280×180)
- `border-dashed`, без заливки
- По центру: `+` (32px, primary) + текст «New workspace»
- Hover: фон `primary / 0.05`

### 3.7. Recent activity

- Под сеткой воркспейсов, отдельная карточка или простой список
- 5 последних коммитов/операций по всем воркспейсам
- Строка: `last commit {time} in {workspace}/{repo} — {message}`
- Кликабельная стрелка `→` ведёт на `/repos/:id`
- Если активности нет — секция скрывается

### 3.8. Empty state (0 воркспейсов)

- Контентная область центрирована
- Слева: круг 240×240 с **радиальным градиентом** от `oklch(0.74 0.18 50 / 0.35)` в центре до `transparent` по краям
- Внутри круга: SVG-иконка лапы (переиспользуем `assets/icon.svg`), 96×96, primary с alpha 0.9
- Справа или ниже: H1 «Create your first workspace», подзаголовок «Workspaces group your local repositories. Pick a folder and we'll scan it for git repos automatically.»
- Primary-кнопка «Create workspace»

### 4.2. Hero воркспейса

- Иконка 56×56 + имя (24/600)
- Мета-строка под именем: `{N} repos · {M} modified · {size}` — `--muted-foreground`
- Полный путь: mono, 12px, ещё более приглушённый, `truncate`
- Справа ghost-кнопка `⚙ Settings` (открывает workspace settings drawer — **это локальные настройки воркспейса**, не путать с иконкой `⚙` в общей шапке, которая ведёт на `/settings` для глобальных)

### 4.3. Toolbar (sticky под hero)

- `Search` — инпут с иконкой лупы, `max-w-xs`, фильтрует репо по имени
- `Group by folder ▾` — дропдаун с двумя значениями: `Group by folder` / `Flat list`. Состояние в `localStorage` под ключом `workspace-view-mode`
- `+ Add repo` — открывает file picker
- `↓ Clone` — ведёт на `/clone` с предзаполненным destination = путь воркспейса

### 4.4. Группировка (по умолчанию включена)

- Сканер воркспейса читает 1 уровень подпапок. Каждая подпапка = группа, имя = имя папки
- Репо из корня воркспейса (не в подпапке) — в группе `Root`
- Все группы развёрнуты по умолчанию
- Заголовок группы: caret + имя + `{N} repos · {size}` справа. Клик сворачивает/разворачивает
- Маленькая dashed-карточка `+ Add to {group}` в конце каждой группы

### 4.5. Карточка репозитория (260×120px)

- Имя (16/500, truncate)
- Статус-точка (та же логика: 🟢/🟡/🔴 по состоянию одного репо)
- Branch badge: моноширинно, с фоном
- Last commit: relative time + первая строка сообщения, truncate
- Ahead/behind: `↑3 ↓1` справа (только если upstream есть)
- Hover: `--shadow-glow` + бордер primary
- Клик → `/repos/:id`

### 4.6. Empty state (воркспейс есть, репо нет)

- Hero воркспейса как обычно
- По центру: иконка папки + «No repositories yet» + «Add an existing folder or clone a repository to get started» + 2 кнопки

### 4.7. Workspace settings drawer

- 480px ширина, выезжает справа
- Секции:
  - **General:**
    - Иконка: large preview (80×80) + кнопка «Change icon» (file picker png/jpg или селект эмодзи)
    - Имя: инпут
    - Путь: read-only mono
  - **Danger zone (внизу):**
    - Красная кнопка `Delete workspace` → confirm dialog «This won't delete files on disk. The folder will stay intact.»
- Закрытие: Esc / клик на backdrop / крестик

## 5. Страница репозитория

Fork-inspired: дерево слева, граф в центре, детали справа.

### 5.1. Структура

```
┌──────────────────────────────────────────────────────────────────┐
│  ‹  ▾ Pet-projects                              ⚙  ◐             │  ← шапка
├────────────────────────────────────────────┬─────────────────────┤
│                                            │                     │
│  ┌──────────────────────────────────────┐  │ ┌─────────────────┐ │
│  │ 🌿 cat-feed                          │  │ │ feat: add paw   │ │
│  │ main · ↑3 ↓1 · 2h ago   [Pull][Push] │  │ │ Alice · 2h ago  │ │
│  └──────────────────────────────────────┘  │ │                 │ │
│                                            │ │ abc1234          │ │
│  ┌──────────┐ ┌─────────────────────────┐  │ │                 │ │
│  │ TREE     │ │ GRAPH (вертикальный,    │  │ │ +12 -4           │ │
│  │          │ │  newest наверху)        │  │ │                 │ │
│  │ ▼ Branches│ │                         │  │ │ src/index.ts     │ │
│  │   main   │ │  ●─●─●─●─●  main       │  │ │  - import x      │ │
│  │   feat-x │ │       \                │  │ │  + import y      │ │
│  │   fix-y  │ │        ●─●  feat-x     │  │ │                  │ │
│  │          │ │           │            │  │ │ [View file]      │ │
│  │ ▼ Tags   │ │           ●  fix-y     │  │ │                  │ │
│  │   v1.0.0 │ │                         │  │ │                  │ │
│  │   v0.9.0 │ │  ↓ load more           │  │ │                  │ │
│  │          │ │                         │  │ │                  │ │
│  │ ▼ Stash  │ │                         │  │ │                  │ │
│  │   WIP    │ │                         │  │ │                  │ │
│  │          │ │                         │  │ │                  │ │
│  └──────────┘ └─────────────────────────┘  │ │                  │ │
│         ↑                 ↑                │ └─────────────────┘ │
│      240px             flexible             │           ↑          │
│                                            │       360-420px      │
└────────────────────────────────────────────┴─────────────────────┘
```

### 5.2. Repo header (под общей шапкой)

- Иконка (40×40) + имя (20/600)
- Справа от имени: branch badge (mono) · ahead/behind (`↑3 ↓1`, цветной по состоянию) · relative time
- Actions справа: `Fetch` (icon-only), `Pull`, `Push`. Счётчик на Pull/Push если есть что тянуть/пушить
- Высота 56px, `border-b border-[var(--border)]`

### 5.3. Левая колонка — Tree (240px, сворачивается до 48px)

- Секции с caret + название + счётчик:
  - **Branches:** локальные ветки. Активная выделена primary. Ветки с unpushed — жёлтая точка. Клик → checkout (с confirm если есть незакоммиченные). `+ New branch` сверху секции
  - **Tags:** список тегов, клик → checkout + actions (delete, push)
  - **Stash:** список записей, клик → pop/apply/drop меню
- Узлы: 14/medium для активной ветки, regular для остальных
- Resize handle справа

### 5.4. Центр — Commit graph (вертикальный, снизу вверх, newest наверху)

- Каждая строка: граф-слева (40px) + 2 строки контента
- Строка 1: short hash (7 символов, mono, secondary) + сообщение (truncate)
- Строка 2: автор · relative time
- Активная ветка выделена primary цветом сообщения
- Merge-коммиты: два входящих узла в графе, ромб вместо круга
- Hover: фон `--surface-elevated`, появляется `⋯` (more actions: copy hash, create patch, revert)
- Клик — выделяет коммит и открывает детали справа
- Виртуализация: `react-window` если коммитов > 500
- Ленивая подгрузка: первые 100, `load more` при скролле вниз

### 5.5. Правая колонка — Detail panel (360-420px)

- Когда ничего не выбрано: «Select a commit to see details» + подсказка про шорткаты
- Когда коммит выбран:
  - Header: сообщение (полное, wrap), автор, дата (полная + relative), хеш (mono, copy-on-click)
  - Действия: `View file`, `Create patch`, `Revert`, `Cherry-pick`, `Reset to here`
  - Stats: `+N -M` строк, файлов
  - Список файлов в коммите — клик expand → inline diff
- **Внизу панели — фиксированный блок «Uncommitted changes»:** счётчик + `Commit` / `Stash` / `Discard`. Раскрывается в file-changes-panel

### 5.6. Модалки операций (Cherry-pick, Revert, Reset, Merge)

- **Command-palette стиль:** центрированная модалка 480×320px
- Превью команды git, которую собираемся выполнить (с подсветкой синтаксиса)
- Кнопка Confirm (primary) + Cancel
- Снижает страх перед деструктивными операциями

- `⌘K` — command palette (глобальный)
- `↑/↓` — навигация по графу
- `Enter` — открыть детали
- `Esc` — снять выделение
