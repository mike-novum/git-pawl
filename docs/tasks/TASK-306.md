# TASK-306 — Граф коммитов: визуальный редизайн под уровень SourceTree / GitKraken

## Контекст
TASK-304 пометил граф как готовый, но визуально он не дотягивает до индустриальных референсов: точки и тонкие линии выглядят «по-дефолтному», иерархия слабая, нет ощущения «дерева». Нужно переосмыслить визуальный дизайн виджета.

В этой задаче — **только визуальный слой**, не меняя структуру `computeLayout` / API. Цель — сделать так, чтобы граф выглядел как профессиональный инструмент (SourceTree, GitKraken, Tower, Sublime Merge, lazygit).

## Референсы (как у других)

| Источник | Что взять |
|---|---|
| **SourceTree** | Скруглённые «рельсы» (rail) для каждой ветки; точки-узлы — круглые; commit hash выделен моноширинным; subject — основной текст; refs (ветки/теги) цветными pills |
| **GitKraken** | Толстые линии (2–3px) с явным изгибом; активная ветка — primary-цвет; неактивные — muted; яркая обводка у выбранного коммита |
| **Tower** | Минималистичный grid, тонкие но контрастные линии, тонкая вертикальная полоса слева для активной строки |
| **Sublime Merge** | Очень лёгкие линии, чёткие «узлы» с внутренним кругом и обводкой, hover — лёгкая подсветка всей строки |
| **lazygit (TUI)** | Контрастные lanes по цвету ветки, символы `*` → красивые круги |

### Шаг 2. Переработать `CommitRow.tsx`
Файл: `src/widgets/repo-graph-vertical/ui/CommitRow.tsx`.

1. **Лейаут строки** — две визуальные зоны:
   - Левая зона (фиксированная ширина `graphWidth`): SVG с lane-линиями и узлом.
   - Правая зона: контент коммита.
2. **Узел (коммит)**:
   - Внешний круг (обводка `--color-surface` толщиной 2px), внутри — заливка `--color-muted-foreground` для неактивных, `--color-primary` для активной ветки, `--color-ring` (или `--color-primary` с большей насыщенностью) для выбранного.
   - При hover — увеличение до `r=5` (или scale) без сдвига (через `transform-origin: center`).
3. **Линии**:
   - `stroke-width: 2` (было `1.5`).
   - Для активной ветки — `stroke: var(--color-primary)`; для остальных — `stroke: var(--color-muted-foreground)` c opacity ~0.5.
   - Скругление `stroke-linecap: round`, радиус кривой `CURVE_RADIUS = 6` (был 4).
   - Линии рисуются под узлами (z-index / SVG layer order).
4. **Контент коммита**:
   - Строка 1: `shortHash` (mono, цвет `--color-muted-foreground`), пробел, `subject` (`--color-foreground`, truncate, font-weight `medium`).
   - Строка 2: chips с ветками/тегами (если есть) + `author · relativeTime` (мелкий, `--color-muted-foreground`).
   - Branch/tag chips: увеличить `h-5` → `h-6`, добавить тонкую цветную полоску слева (3px) в цвет ветки, либо оставить outline + иконку.
5. **Hover/selected row**:
   - Лёгкий фон `--color-surface-elevated`.
   - Активная строка — лёгкая левая вертикальная полоса 2px `--color-primary` (как в Tower) — добавить `border-l-2 border-primary` при `isSelected || isActive`.
6. **Разделители строк** убрать или сделать `divide-y divide-border/20` тоньше.
