# TASK-102 — Анимации и микровзаимодействия

## Acceptance criteria
- [ ] Все Dialog/Sheet открываются с плавной анимацией (`--duration-base`, `ease-fast`).
- [ ] Hover/focus — subtle transitions.
- [ ] Toast появляется снизу-справа, плавно.
- [ ] Никаких layout-shifts.
- [ ] Никаких анимаций > 250 ms.

## Зависит от
- TASK-002, TASK-012

## Статус

**Deferred** — анимации не реализованы. Без конкретного UI-дизайна (кривые, тайминги, keyframes) добавлять микровзаимодействия рано: легко сделать «правильные» анимации, которые потом придётся переделывать под дизайн-систему. Задача остаётся в бэклоге и может быть поднята отдельным таском, когда появится визуальная спецификация.
